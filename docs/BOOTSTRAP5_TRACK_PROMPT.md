## COMPILER REQUIREMENTS

### CDN Setup
CSS:
https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css

JS:
https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js

### Execution System
- iframe-based renderer
- full ES6 + Bootstrap support
- no jQuery dependency
- live reload preview

### Supported Features
- Offcanvas
- Toast notifications
- Accordion
- Scrollspy
- Modal system
- Tooltips (native Bootstrap 5 JS)
