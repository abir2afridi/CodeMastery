# Flexbox transition framework (Bootstrap 4)

## OVERVIEW

Bootstrap 4 is a transition version between Bootstrap 3 and 5.

This track teaches:
- Flexbox-based layout system
- Utility-first spacing system
- Card-based UI (replacing panels)
- Modern responsive design patterns

Students learn:
- Modern frontend layout evolution
- Real-world enterprise migration (BS3 → BS4 → BS5)
